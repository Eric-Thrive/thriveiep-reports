Ben Sghaier et al., 2026 | 2 citations

WiseSpec: Requirements-Driven Agents for Code Generation arXiv [4]

Tian, 2026

Argues coding-agent failures often trace to poor requirements rather than model capability; iteratively refining requirements via execution-based evaluation yields a 13.17% average gain in %Resolved.

Echoes the prompt-formalizer / spec-first approach: sharpen the requirement before implementation and the model matters less.

ExecRetrieval: Measuring the Functional-Correctness Gap in Code-Embedding Retrieval arXiv [5]

Kapoor & Khan, 2026

A 939-task benchmark plants execution-verified buggy near-clones in the retrieval pool; the best hosted embedding system hits exec@10=1.00 but only exec@1=0.331, so agent retrieval often ranks a buggy variant above the correct one.

Caution for retrieval-backed code navigation (our code-graph tooling): top-1 hits can be plausible-but-wrong.

A Finger on the Scale: Covert Policy Steering through Agentic Skills arXiv [37]

Li et al., 2026

"SkillShift" is a supply-chain attack that covertly redirects an agent's decisions via a reusable third-party Skill while preserving declared functionality (81%/63% attacker-favored selection, 100% utility preserved), and existing scanners miss it.

We run a large Skills library. Skills are trusted code paths; this argues for provenance and integrity checks on third-party skills.

Public-Sharing Labels and Verbatim Field Egress in an MCP-to-A2A Configuration arXiv [36]

Mahapatra, 2026 | 480-trial controlled study

Adding a "PUBLIC - OK TO SHARE" label strongly and consistently increased verbatim data leakage specifically for Claude Sonnet 5 across MCP tool-use and A2A delegation legs, with weaker effects on other models.

Concrete data-egress caution for our MCP stack and the Sonnet-5 cheap-tier delegation path: untrusted "sharing" labels can pry data loose.

ACLE-MCP: Attested Capability Leases for Execution-Time Trust in Remote LLM Tool Use arXiv [38]

Ding et al., 2026

Identifies a post-authorization execution trust gap in remote MCP (OAuth alone does not guarantee a later call runs on the trusted workload); a Keycloak/OIDC prototype with short-lived leases blocked all evaluated attacks at a 25.7% p95-latency cost.

Harness Engineering via Agent-Native Reusable Tool Primitives (HEART) arXiv [39]

Jin et al., 2026

Natural-language "Tool Primitives" replace rigid API schemas alongside a 25,519-function retrieval repository; HEART beats GPT-5.4, Claude-4.6-Sonnet, and Gemini-3.1-Pro by 6% on average while cutting API cost up to 85%.

Same theme as our cost doctrine: harness design (not just model choice) buys both quality and large token savings.

CivBench: A Long-Horizon Benchmark for Tool-Mediated Agents in Civilization VI arXiv [40]

Andrews et al., 2026
